# Gamescom Website

A responsive website project created for a Gamescom-themed web experience. The project focuses on presenting gaming-related content in a modern and interactive way, using clean layouts, visual sections, and simple user interactions.

The website was built with HTML, CSS, and JavaScript, with attention to responsive design, structure, and usability.

## Features

- Responsive layout for desktop and mobile
- Gamescom-themed design
- Interactive elements with JavaScript
- Organized project structure
- Custom styling with CSS

## Tech Stack

HTML · CSS · JavaScript

## Installation & Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Gokusan453/gamescom.git
   ```

2. Open the project folder:
   ```bash
   cd gamescom
   ```

3. Open `index.html` in your browser.
